## 2. Краткие теоретические сведения

* **Архитектура и выполнение кода:** Язык Python является интерпретируемым. При первом запуске исходный код транслируется в промежуточный платформонезависимый байт-код (`.pyc`) и исполняется виртуальной машиной Python (PVM).
* **Переменные и типизация:** Переменные в Python представляют собой динамически связываемые ссылки (имена), указывающие на объекты в оперативной памяти. Типизация является сильной динамической.
* **Синтаксис блоков:** Отступы (в соответствии с PEP 8 — ровно 4 пробела) являются синтаксически обязательными и заменяют фигурные скобки других языков для определения границ блоков инструкций.
* **Форматирование строк:** Метод `format()` позволяет форматировать строки согласно спецификации PEP 3101 (например, выражение `'{0:.3f}'.format(pi)` форматирует вещественное число с точностью до трех знаков после запятой). В современном Python также широко применяются интерполированные f-строки (`f"..."`), отличающиеся более компактным и читаемым синтаксисом.

## 3. Задание

Написать скрипт, вычисляющий физическую величину по формуле. Все переменные должны быть динамически привязаны к значениям. Вывод результата осуществить с округлением вещественной части до 4 знаков после запятой. Исходные параметры ввести с помощью функции `input()`.

### Вариант №8
Расчет кинетической энергии вращательного движения:
$$E = \frac{J \cdot \omega^2}{2}$$

**Параметры:**
* $J = 1.25$ $\text{кг}\cdot\text{м}^2$ (момент инерции)
* $\omega = 314$ $\text{рад/с}$ (угловая скорость)

---

## 4. Исходный код программы

```python
# J = 1.253, w = 314
J = float(input("Величина J (кг*м^2): "))  # Ввод переменной J
w = float(input("Величина W (рад/c): "))   # Ввод переменной w

# Вывод значения E с округлением до четырех знаков после запятой
print(f"Кинетическая энергия вращения (E) = {round((J * w**2) / 2, 4)} Дж")
```

---

## 5. Используемые средства и конструкции языка

* `input()` — функция чтения строковых данных, введенных пользователем с клавиатуры через стандартный поток ввода `sys.stdin`.
* `float()` — функция явного приведения строкового типа к типу чисел с плавающей точкой (`float`).
* `round(value, n)` — встроенная функция математического округления значения `value` до `n` знаков после запятой.
* `print()` — функция стандартного вывода информации в консоль / терминал.
* **f-строки (литералы форматированных строк):** конструкция вида `f"..."`, позволяющая вычислять выражения внутри фигурных скобок `{}` непосредственно во время выполнения.
