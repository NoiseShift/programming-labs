## 2. Краткие теоретические сведения

### 2.1. Модульная организация программ и системные модули
* **Модуль в Python:** Представляет собой отдельный файл с расширением `.py`, содержащий определения функций, переменных и классов. Модульная архитектура обеспечивает повторное использование кода и декомпозицию сложных программных комплексов.
* **Импорт модулей:** Для подключения встроенных или внешних модулей используется оператор `import module`. Для импорта конкретных функций используется форма `from module import function`. Также возможно задание псевдонима с помощью ключевого слова `as` (`import module as alias`).
* **Точка входа `__name__`:** При импорте модуля весь его код исполняется один раз. Чтобы отделить код тестирования/запуска от используемого функционала библиотеки, применяется проверка специальной переменной:
  ```python
  if __name__ == '__main__':
      ...
  ```
* **Системный модуль `sys` и переменная `sys.argv`:** Модуль `sys` предоставляет доступ к параметрам среды исполнения. Переменная `sys.argv` представляет собой список строк, содержащий аргументы командной строки, переданные программе при ее запуске из консоли (`sys.argv[0]` — имя запускаемого скрипта, последующие элементы — переданные параметры).

### 2.2. Базовые структуры данных
Python содержит четыре основные встроенные структуры данных:
1. **Списки (`list`):** Упорядоченные динамические массивы элементов произвольных типов (`[]`). Являются изменяемыми (*mutable*), поддерживают добавление (`append()`), сортировку (`sort()`) и удаление элементов (`pop()`, `remove()`, `del`).
2. **Кортежи (`tuple`):** Упорядоченные неизменяемые (*immutable*) последовательности элементов (`()`). Применяются для защиты данных от случайной модификации, компактного хранения и возврата нескольких значений из функций.
3. **Словари (`dict`):** Ассоциативные массивы, хранящие пары «ключ: значение» (`{}`). Ключи должны быть уникальными и неизменяемыми объектами (строки, числа, кортежи).
4. **Множества (`set`):** Неупорядоченные коллекции уникальных элементов. Поддерживают математические операции над множествами: объединение (`|`), пересечение (`&`), разность (`-`).

### 2.3. Индексация и операции срезов
Последовательности (списки, кортежи, строки) поддерживают обращение к элементам по индексам и получение фрагментов с помощью срезов. Синтаксис среза имеет вид:
```text
sequence[start:stop:step]
```
где:
* `start` — начальный индекс (включительно);
* `stop` — конечный индекс (не включительно);
* `step` — шаг извлечения элементов.

* **Отрицательные индексы:** Отсчитываются от конца последовательности (`-1` соответствует последнему элементу).
* **Разворот последовательности:** Срез со значением шага `-1` (например, `sequence[::-1]`) выполняет быстрый разворот последовательности в обратном порядке без изменения исходного объекта.

## 3. Задание

Робот-манипулятор перемещает детали по заданной пространственной траектории $(x, y, z)$. Программа управления должна валидировать координаты на выход за границы рабочей зоны, сглаживать траекторию и формировать обратный путь для возврата в исходную позицию.

### Задачи модуля (`utils/variant_mod.py`):
1. `validate_coordinates(point_tuple, limits_dict)` — проверяет кортеж координат $(x, y, z)$ на попадание в допустимые диапазоны по осям.
2. `smooth_trajectory(points_list)` — выполняет сглаживание точек траектории по методу скользящего усреднения троек смежных точек.
3. `get_reversed_path(points_list)` — возвращает обратный путь манипулятора с помощью среза `[::-1]`.

### Требования к программе (`main.py`):
1. Считать координату для проверки из аргументов командной строки (`sys.argv[1]`).
2. Задать траекторию из кортежей точек, выполнить валидацию координат и сформировать обратный путь.

## 4. Исходный код программы

### Модуль `variant_mod.py` (`utils/variant_mod.py`)

```python
def validate_coordinates(point_tuple, limits_dict):
    """Проверяет попадание точки (x, y, z) в допустимые пределы."""
    x, y, z = point_tuple
    x_min, x_max = limits_dict['x']
    y_min, y_max = limits_dict['y']
    z_min, z_max = limits_dict['z']
    return (x_min <= x <= x_max) and (y_min <= y <= y_max) and (z_min <= z <= z_max)


def smooth_trajectory(points_list):
    """Выполняет сглаживание пространственной траектории."""
    if len(points_list) < 3:
        return list(points_list)
    
    smoothed = [points_list[0]]
    for i in range(1, len(points_list) - 1):
        prev_p = points_list[i - 1]
        curr_p = points_list[i]
        next_p = points_list[i + 1]
        new_point = tuple((prev_p[j] + curr_p[j] + next_p[j]) // 3 for j in range(3))
        smoothed.append(new_point)
    smoothed.append(points_list[-1])
    return smoothed


def get_reversed_path(points_list):
    """Возвращает обратный путь манипулятора с использованием среза."""
    return points_list[::-1]
```

### Основной модуль `main.py`

```python
import sys
import utils.variant_mod as variant_mod


def main():
    if len(sys.argv) < 2:
        print("Использование: python main.py <координата>")
        return
    
    coord_to_check = float(sys.argv[1])
    path = [(10, 20, 0), (50, 60, 30), (100, 120, 50)]
    limits = {'x': (0, 200), 'y': (0, 200), 'z': (0, 100)}
    test_point = (coord_to_check, 100, 50)
    
    is_valid = variant_mod.validate_coordinates(test_point, limits)
    if is_valid:
        status = "допустима"
    else:
        status = "выход за границы"
    
    print(f"Проверка точки {test_point}: {status}")
    
    smoothed = variant_mod.smooth_trajectory(path)
    print(f"Сглаженная траектория: {smoothed}")
    
    reversed_path = variant_mod.get_reversed_path(path)
    print("=== ТРАЕКТОРИЯ РОБОТА-МАНИПУЛЯТОРА ===")
    print(f"Исходная траектория: {len(path)} точки")
    print(f"Обратный путь (срез [::-1]): {reversed_path}")


if __name__ == "__main__":
    main()
```

## 5. Используемые средства и конструкции

1. **Модульная организация и импорт:**
   * `import sys` — подключение встроенного системного модуля для взаимодействия с интерпретатором и обработки аргументов командной строки.
   * `import utils.variant_mod as variant_mod` — импорт пользовательского модуля с заданием псевдонима (`alias`) для реализации принципа декомпозиции кода и повторного использования функций.
   * `if __name__ == "__main__":` — проверка точки входа для разделения основного исполняемого кода скрипта и импортируемого функционала модуля.
2. **Системный модуль `sys`:**
   * `sys.argv` — список аргументов командной строки, используемый для передачи динамических параметров скрипту (в частности, координаты `coord_to_check`).
   * `len(sys.argv)` — проверка количества переданных аргументов для обеспечения отказоустойчивости программы.
3. **Базовые структуры данных:**
   * **Списки (`list`):** динамические изменяемые коллекции для хранения траектории движения робота-манипулятора (`path = [...]`, `smoothed = [...]`).
   * **Кортежи (`tuple`):** неизменяемые упорядоченные последовательности для представления пространственных координат точек $(x, y, z)$ (`(10, 20, 0)`, `test_point`), а также распаковка кортежей (`x, y, z = point_tuple`).
   * **Словари (`dict`):** ассоциативные массивы для хранения допустимых диапазонов рабочей зоны по осям в формате «ключ — значение» (`limits = {'x': (0, 200), ...}`).
4. **Операции со срезами (Slices):**
   * `points_list[::-1]` — применение среза с отрицательным шагом `-1` для быстрого разворота последовательности и формирования обратного пути манипулятора.
5. **Управляющие конструкции и функции:**
   * **Пользовательские функции (`def`):** создание изолированных блоков кода с передачей параметров и возвратом результата через оператор `return` (`validate_coordinates`, `smooth_trajectory`, `get_reversed_path`).
   * **Условные операторы (`if`-`else`):** проверка условий попадания точки в рабочую зону и наличия аргументов командной строки.
   * **Цикл `for` и функция `range()`:** итерационный перебор элементов с заданием индексов (`range(1, len(points_list) - 1)`) для сглаживания траектории движения.
   * **Генераторы (выражения-генераторы):** компактное вычисление координат сглаженной точки внутри кортежа (`tuple(... for j in range(3))`).
   * **Форматированный вывод (f-строки):** вывод результатов работы программы с интерполяцией переменных (`print(f"...")`).
