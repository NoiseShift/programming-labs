## 2. Краткие теоретические сведения

* **Условный оператор `if`-`elif`-`else`:** Используется для проверки логических условий и ветвления алгоритма. Конструкция `elif` позволяет связывать несколько последовательных проверок без добавления лишней вложенности отступов. Блок `else` выполняется, если ни одно из условий не подтвердилось. Обязательным синтаксическим правилом является использование двоеточия (`:`) и строгое соблюдение отступов (4 пробела).
* **Цикл `while`:** Выполняет блок выражений до тех пор, пока проверяемое условие истинно (`True`). Для экстренного выхода из цикла применяется оператор `break`, а для перехода к следующей итерации — `continue`. При естественном завершении цикла выполняются команды из необязательного блока `else`.
* **Цикл `for..in` и функция `range()`:** Осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция `range(start, stop, step)` генерирует арифметическую прогрессию чисел, не включая верхнюю границу `stop`.
* **Пользовательские функции (`def`):** Представляют собой многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова `def`, принимает параметры и возвращает результаты вычислений оператором `return`. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции для описания ее назначения.

## 3. Задание

Разработать функцию `simulate_robot_braking(v0, deceleration, time_step)`, моделирующую в цикле `while` пошаговое торможение:

$$v = v - a \cdot t \quad \text{до} \quad v \le 0$$

При флаге экстренной остановки прерывать цикл. Функция возвращает пройденный тормозной путь и время.

---

## 4. Исходный код программы

```python
def simulate_robot_braking(v0, deceleration, time_step, emergency_stop: bool = False):
    v = v0
    total_t = 0
    while v > 0:
        if emergency_stop:
            break
        v = v - deceleration * time_step
        total_t += time_step
    s = v0 * total_t / 2
    return [s, total_t]


v1 = float(input('Начальная скорость: '))
a = float(input('Торможение: '))
t = float(input('Шаг времени: '))

print(simulate_robot_braking(v1, a, t))
```

---

## 5. Используемые средства и конструкции

1. **Пользовательские функции (`def`):** Объявлена функция `simulate_robot_braking(...)` для расчетного моделирования пошагового торможения робота.
2. **Аннотация типов и значения по умолчанию:** Для параметра `emergency_stop: bool = False` указан тип данных (`bool`) и значение по умолчанию (`False`), что позволяет осуществлять вызов функции как с тремя, так и с четырьмя аргументами.
3. **Возврат значений (`return`):** Оператор `return [s, total_t]` возвращает результаты вычислений (расчетный тормозной путь и общее время) в виде списка.
4. **Условный оператор (`if`) и досрочный выход (`break`):** Конструкция `if emergency_stop: break` проверяет флаг аварийного останова и прерывает цикл.
5. **Цикл с предусловием (`while`):** `while v > 0:` моделирует процесс замедления до полной остановки ($v \le 0$).
6. **Составное присваивание (`+=`):** Конструкция `total_t += time_step` выполняет итерационное накопление общего времени торможения.
7. **Ввод/вывод и приведение типов (`input`, `float`, `print`):** Функция `input()` запрашивает значения с клавиатуры, `float()` преобразует введенный текст в вещественные числа, а `print()` выводит итоговый результат.
